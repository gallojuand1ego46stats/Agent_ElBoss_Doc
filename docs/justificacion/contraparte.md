# Contraparte

## Contraparte primaria

**Juan Diego Gallo Quintero**, estudiante de Estadística y usuario directo de procesos de análisis y generación de reportes estadísticos a partir de bases de datos.

La elección de esta contraparte se fundamenta en la experiencia directa con el problema que motiva el proyecto: preparar, explorar, analizar e interpretar datos y posteriormente estructurar un reporte estadístico reproducible.

## Usuarios objetivo secundarios

El proyecto también está orientado a usuarios que realizan procesos similares, entre ellos:

- estudiantes de Estadística;
- estadísticos;
- analistas de datos;
- usuarios que necesiten transformar una base de datos estructurada en un reporte estadístico.

Estos perfiles se consideran **usuarios objetivo secundarios**, no sustituyen a la contraparte primaria utilizada para delimitar la necesidad inicial.

## Necesidad identificada

La necesidad consiste en reducir el trabajo repetitivo asociado al proceso de generación de reportes estadísticos, manteniendo un pipeline estadístico verificable y una salida final en PDF.

La necesidad parte de una experiencia de uso real del proceso y se busca convertirla en una solución reproducible y reutilizable.

## Evidencia pendiente

Para fortalecer la evidencia de contraparte se incorporará posteriormente, cuando esté disponible:

- fecha y contexto del encargo o necesidad;
- descripción de una tarea concreta realizada por la contraparte;
- evidencia de la línea base;
- resultado de una prueba de uso del agente.

No se afirma la existencia de documentos de encargo adicionales que no hayan sido recopilados.
